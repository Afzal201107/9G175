Чтобы ваш HTML-файл стал полноценным сайтом, доступным в интернете 24/7, его нужно загрузить на хостинг статических сайтов Reddit. Это специальные облачные сервисы, которые хранят файлы на своих серверах, работают без перерывов и предоставляют бесплатный доступ. Перед загрузкой обязательно переименуйте ваш главный HTML-файл в index.html (все буквы должны быть строчными). Серверы всегда ищут файл с таким именем, чтобы открыть главную страницу сайта. Вот три лучших бесплатных и простых способа разместить ваш сайт: Способ 1: GitHub Pages (Самый популярный и надежный) Этот вариант идеален, если вы планируете обновлять сайт в будущем. Зарегистрируйтесь на сайте GitHub. Создайте новый репозиторий (нажмите New repository). В названии укажите, например, my-first-site. Обязательно сделайте его Public. Нажмите ссылку uploading an existing file и перетащите ваш файл index.html (а также папки со стилями CSS и картинками, если они есть) в окно браузера. Нажмите Commit changes внизу. Перейдите в настройки репозитория (Settings) -> вкладка Pages (в левом меню). В разделе Build and deployment выберите ветку main (или master) вместо None и нажмите Save. Через 1–2 минуты страница обновится, и вверху появится готовая ссылка на ваш сайт (формата имя_пользователя.github.io/название_репозитория). Способ 2: Netlify (Самый быстрый, без регистрации репозиториев) Отличный вариант, если хочется запустить сайт буквально за 10 секунд без работы с кодом Reddit. Зайдите на Netlify и зарегистрируйтесь (можно войти через Google). Перейдите в раздел Sites. В самом низу страницы вы увидите блок с надписью "Want to deploy a new site without connecting to Git? Drag and drop your site folder here". Положите ваш файл index.html в отдельную папку на компьютере и просто перетащите эту папку в это поле на сайте. Сервис мгновенно сгенерирует для вас случайный бесплатный адрес (например, beautiful-cookies-12345.netlify.app), который будет работать круглосуточно. В настройках сайта это имя можно бесплатно изменить на любое свободное. Способ 3: Vercel (Профессиональный и быстрый) Похож на Netlify, имеет отличную скорость загрузки страниц. Зарегистрируйтесь на Vercel. На панели управления выберите Add New -> Project. Вы можете загрузить файлы напрямую, перетащив папку с сайтом (инструмент Vercel CLI или ручной импорт папки), либо связать аккаунт с вашим GitHub и развернуть сайт оттуда в один клик. Вы получите постоянный бесплатный домен вида ваш_проект.vercel.app. Важный нюанс: Все эти сервисы абсолютно бесплатны и ваш сайт будет доступен круглосуточно, даже если ваш ПК выключен. Однако они дают системный адрес (домен третьего уровня). Если вы захотите, чтобы сайт открывался по красивому адресу вроде mysite.com, вам нужно будет отдельно купить доменное имя у любого регистратора доменов и привязать его в настройках выбранного хостинга Ответы Mail.ru. Я могу пошагово провести вас через весь процесс загрузки. Вы зашли на главную страницу (Dashboard) GitHub, и с мобильного интерфейса кнопка создания нового репозитория спрятана в меню. Чтобы загрузить ваш HTML-файл, выполните следующие шаги: Откройте главное меню: Нажмите на иконку с тремя горизонтальными полосками (гамбургер-меню) в левом верхнем углу экрана. Создайте репозиторий: В открывшемся боковом меню найдите раздел Repositories и нажмите кнопку New (или знак + рядом с ним), чтобы начать создание нового проекта. Заполните настройки: В поле Repository name введите название на английском (например, my-site). Убедитесь, что выбран вариант Public (чтобы сайт был виден всем). Поставьте галочку на пункте Add a README file — это важно, так как мобильная версия GitHub не позволит загрузить файлы через браузер в абсолютно пустой репозиторий. Нажмите зеленую кнопку Create repository в самом донышке страницы. Когда создадите репозиторий и перед вами откроется его страница, дайте знать. Кнопка загрузки файлов в мобильной версии тоже имеет свой нюанс — я подскажу, куда именно нажать, чтобы добавить ваш index.html. Отлично, репозиторий успешно создан! Теперь нужно загрузить ваш HTML-файл. Так как вы делаете это с телефона, кнопка загрузки скрыта. Вот что нужно сделать: Нажмите на кнопку с тремя точками ..., которая находится в верхней правой части экрана (справа от зеленой кнопки Code). В появившемся меню выберите пункт Upload files (Загрузить файлы). Нажмите на ссылку choose your files (выбрать файлы) и выберите ваш HTML-файл (он обязательно должен называться index.html строчными буквами). Если к сайту идут картинки или стили, выберите и их тоже. Прокрутите страницу в самый низ и нажмите зеленую кнопку Commit changes (Сохранить изменения). Как только файлы загрузятся и вы снова окажетесь на этой странице, напишите — мы включим отображение сайта, чтобы он заработал по ссылке. Ничего страшного, это обычное дело для полноценного сайта! GitHub Pages без проблем поддерживает картинки, аудиофайлы и любые другие медиафайлы. Чтобы всё работало правильно, самое главное — сохранить правильные пути к файлам.
